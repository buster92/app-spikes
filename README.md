# App Spikes

Small, fast product experiments. Each spike should answer a concrete product hypothesis before it grows into a larger project.

## Current spikes

- [`playable-feed/`](playable-feed/) — a swipeable feed of lightweight playable microgames, instrumented to test whether people voluntarily keep playing and swiping.

## Spike rule

Build the smallest version that can falsify the core hypothesis. Instrument behavior from day one. Expand only after the data gives a reason to.
